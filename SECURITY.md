# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within htmx-magnify, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please report the issue through [GitHub's private vulnerability reporting](https://github.com/Sandeepv68/htmx-magnify/security/advisories/new).

## Response Timeline

- Acknowledgment within 48 hours
- Assessment within 1 week
- Fix or mitigation plan communicated within 2 weeks

## Scope

This policy applies to vulnerabilities found in the `htmx-magnify` package distributed via npm or this repository.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |
| < 1.0   | No        |
