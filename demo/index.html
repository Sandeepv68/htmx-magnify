htmx-magnify v1.0.0

htmx extension for image magnification with zoom glass effect

Basic Usage

<div hx-magnify
     hx-magnify-src="image.jpg"
     hx-magnify-width="120"
     hx-magnify-height="120"
     hx-magnify-zoom="2.5">
  <img src="image.jpg" alt="Product" />
</div>
